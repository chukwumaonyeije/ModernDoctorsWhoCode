## Editorial Prompt

Write a DoctorsWhoCode.blog essay in Dr. Chukwuma Onyeije's physician-developer voice arguing that AI coding agents do not replace software fundamentals. They expose whether the builder has any.

Use this framing:

- Start with a concrete question from a physician about whether agents mean doctors no longer need to learn software engineering.
- Reframe the issue quickly: the old rules have not disappeared; they have become more visible.
- Explain why agents perform well inside structured systems and poorly inside chaotic ones.
- Use the concept of a model's "smart zone" and "dumb zone" to explain why context windows alone do not solve judgment.
- Show why vertical slices beat sprawling tasks for physician-builders.
- Connect software fundamentals to agent safety: modularity, testing, domain modeling, observability, version control, and documentation.
- Compare agent supervision to supervised autonomy in medicine without anthropomorphizing the agent.
- Raise the stakes for clinical-adjacent software: chart orientation, documentation, billing, protocols, decision support, and patient communication.
- Emphasize that the harness is the product: retrieval, prompt boundary, validation, audit log, UI, failure state, review workflow, and human accountability.
- End with a firm, forward-looking point: agentic engineering is not magic; it is disciplined professional tool use.

Style constraints:

- Direct, declarative, first-person when appropriate.
- Short paragraphs.
- Active voice.
- System-level framing, not user blame.
- Avoid AI filler and corporate language.
- Avoid em dashes in body copy.
- Make the conclusion concrete and accountable.
