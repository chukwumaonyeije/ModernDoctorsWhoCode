This six-part course starts with a local teaching notebook and follows its tools toward a stateless Cloudflare project. Part 1 is available now. Later lessons will cover local tool inspection, hosting, source metadata, access boundaries and a reproducible release.

Each session has a two-hour learning budget. The displayed course duration reflects available lessons only; it grows as later lessons are released. All examples use synthetic or verified public material, with no patient information or clinical recommendations.
